Descripción del Proyecto

SensoraCore es un sistema completo de monitoreo de sensores que combina hardware ESP32 con una aplicación de escritorio desarrollada en Python con PySide6. Está diseñado para aplicaciones educativas y de prototipado, y permite la lectura, visualización y análisis de múltiples tipos de sensores digitales y analógicos a través de conexión WiFi.

El ESP32 ejecuta un firmware en MicroPython que actúa como servidor TCP y envía las lecturas a la aplicación, donde se grafican en tiempo real, se calibran y se exportan a Excel con gráficas y estadísticas. El proyecto está pensado para estudiantes, educadores, makers, ingenieros y desarrolladores interesados en IoT, robótica y sistemas embebidos, e incluye manuales técnicos, manuales de usuario y prácticas de laboratorio para cada sensor.

Objetivos
  • Desarrollar módulos didácticos para la caracterización y calibración de sensores industriales.
  • Ofrecer una plataforma accesible y robusta para el aprendizaje y el desarrollo de proyectos IoT.
  • Integrar sensores digitales y analógicos con análisis de datos en tiempo real.
  • Permitir la calibración persistente de cada sensor y la exportación de datos para análisis científico.
Resultados
  • 12 módulos de sensores funcionales, más los módulos base de conexión WiFi (Connect) y lectura del ESP32 (ESP Reading).
  • Calibración lineal con parámetros guardados por sensor en JSON y flujos guiados paso a paso para los módulos de brillo y gas.
  • 14 módulos de software registrados ante la Dirección Nacional de Derechos de Autor (DNDA).
  • Documentación completa: 14 manuales técnicos de software, 12 manuales de usuario, 12 prácticas de laboratorio, documentación de código.
Características Principales
Conectividad WiFi

Comunicación inalámbrica TCP/IP entre el ESP32 y la aplicación de escritorio, con reconexión automática.

12+ sensores soportados

Potenciómetros, infrarrojos, capacitivos, ultrasónicos, temperatura, gases, luz y color.

Visualización en tiempo real

Gráficas dinámicas con matplotlib y actualización instantánea de los datos.

Exportación a Excel

Mediciones guardadas con gráficos embebidos y estadísticas automáticas.

Interfaz intuitiva

Interfaz moderna desarrollada con PySide6, fácil de usar.

Calibración integrada

Calibración lineal y guardado de parámetros por sensor.

Módulos de Sensores
  • Simple Angle: potenciómetro como sensor de ángulo (0-270°).
  • Angle Arm: varios potenciómetros que simulan un brazo robótico.
  • Infrared: sensor de proximidad IR (Sharp GP2Y0A21YK).
  • Capacitive: sensor capacitivo digital para detección de proximidad.
  • Ultrasonic: sensor de distancia HC-SR04 (2-400 cm).
  • Optical Speed: control y monitoreo de velocidad con sensor óptico.
  • IR Steering: sistema de dirección basado en infrarrojos.
  • Thermoregulation: sensores LM35, DS18B20 y MAX6675 (termopar tipo K).
  • Gas Regulation: sensores MQ2/MQ3 con cálculo real de PPM.
  • Brightness: sensor LDR para medición de luminosidad.
  • Color CNY: detección de color con sensores CNY70.
  • Color TCS: sensor de color TCS3200 con filtros RGB.
  • Connect y ESP Reading: módulos base de conexión WiFi y lectura del ESP32.
Arquitectura del Sistema
Hardware
  • Microcontrolador ESP32 con WiFi integrado.
  • Sensores digitales y analógicos de diversos tipos.
  • Comunicación TCP/IP sobre WiFi.
  • Pantalla OLED I2C opcional para el estado local.
Firmware ESP32
  • Lenguaje MicroPython.
  • Servidor TCP en el puerto 8080.
  • Datos en texto plano con formato SENSOR:valor.
  • Módulos principales red.py y main.py.
Aplicación de escritorio
  • PySide6 (Qt for Python).
  • matplotlib para las gráficas.
  • openpyxl para la exportación a Excel.
  • Un módulo por sensor, con ejecución en hilos.
Documentación
  • Manuales de software (14): documentación técnica del código, arquitectura de módulos, protocolos de comunicación y guías de desarrollo.
  • Manuales de usuario, serie A (12): operación, conexiones de hardware, configuración y uso básico de cada sensor.
  • Prácticas de laboratorio, serie B (12): ejercicios prácticos, experimentos guiados y actividades didácticas.
  • Documentación de código, maquetación de la interfaz, guía de inicio rápido y lista de sensores.
Propiedad Intelectual

Los 14 módulos de software de SensoraCore (los 12 sensores, Connect y ESP Reading) están registrados ante la Dirección Nacional de Derechos de Autor (DNDA) de Colombia. Los certificados validan la autoría y la fecha de creación de cada componente.

Evolución del Proyecto
  • Alpha 0.1 (25 de mayo de 2025): primera versión funcional con conexión WiFi, sensor de ángulo, interfaz de dos paneles y exportación a Excel.
  • Alpha 0.2.0 - 0.2.2 (mayo de 2025): sistema híbrido digital/analógico; se suman el sensor ultrasónico, el brazo robótico, los sensores IR y capacitivos, y correcciones de interfaz y del graficador.
  • Alpha 0.2.3 (29 de mayo de 2025): primera versión estable, completamente funcional con 5 sensores y lista para uso educativo.
  • Alpha 0.2.4 (23 de junio de 2025): versión intermedia de preparación para la refactorización hacia la Beta.
  • Beta 1.0 (25 de agosto de 2025): sistema completo tras tres meses de refinamiento: compilador terminado, todos los módulos finalizados, calibración persistente, pantalla OLED, firmware optimizado y exportación a Excel mejorada.
  • Beta 2.0 (23 de noviembre de 2025): versión actual, con mejoras sobre la 1.0 y pruebas extensivas. Incluye la IP en la pantalla OLED durante el modo de espera, un script de compilación optimizado y protocolos de comunicación actualizados entre firmware y aplicación.
