Descripción del Proyecto

Herramienta de uso personal para traducir texto al instante desde el escritorio. Es una extensión para GNOME Shell 45+ que añade un menú de traducción en el panel superior, con más de 80 idiomas y detección automática mediante el endpoint gratuito de Google Translate, sin API Key. Incluye historial, copia automática al portapapeles, atajo global (Super+T), apariencia personalizable y paquetes de idioma descargables para la interfaz. El repositorio incluye además una versión para Windows en Electron que vive en la bandeja del sistema.

Objetivos
  • Traducir texto sin salir del escritorio ni abrir el navegador
  • Evitar claves de API y configuraciones adicionales
  • Permitir personalizar colores, ícono y opacidad del menú
  • Llevar la misma herramienta a Windows
Resultados
  • Extensión funcional para GNOME Shell 45, 46, 47 y 48
  • Preferencias en libadwaita con páginas de Apariencia, Idiomas y Avanzado
  • Interfaz traducida a 11 idiomas mediante paquetes descargables
  • Aplicación de bandeja para Windows con historial y atajo Ctrl+Shift+T
