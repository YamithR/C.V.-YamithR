BORRAR ESTE BLOQUE EN EL PROYECTO REAL

Instrucciones de la plantilla

Esta página reúne todos los módulos que se han usado en las páginas de proyecto del sitio. Debajo de esta tarjeta verás cada módulo funcionando con medios reales del repositorio, para que puedas ver cómo se ve antes de usarlo.

Paso a paso
  1. Copia este archivo dentro de proyectos/ y renómbralo con el nombre del proyecto, usando guiones bajos en lugar de espacios. Ejemplos existentes: Puesta_en_Marcha_SCORBOT.html, Mecanismos_de_Encoders_de_M2.50.html, MOMO-BoatController-RPi4.html. Recomendado: evita tildes y la letra ñ en el nombre del archivo.
  2. Guarda los medios en carpetas con el nombre del proyecto: imágenes en assets/img/<Proyecto>/ y videos y GIF en assets/vid/<Proyecto>/. Desde la página se enlazan con ../, por ejemplo ../assets/img/MiProyecto/foto.jpg.
  3. Arma la página por módulos. Cada módulo está delimitado por los comentarios <!-- ===== MÓDULO: ... ===== --> y <!-- ===== FIN MÓDULO: ... ===== -->. Puedes conservar, duplicar o borrar todo lo que esté entre ambos comentarios sin romper la página. Dentro de cada módulo hay un comentario corto con su propósito, qué cambiar y de qué depende.
  4. Elige la variante del encabezado (hero). Hay cuatro variantes juntas en el módulo "Hero": imagen fija (A, activa), GIF animado (B), video en bucle sin sonido (C) y video con controles (D). Deja solo una sin comentar.
  5. Reemplaza todo el texto de ejemplo ("Nombre del Proyecto", "Descripción breve...", etc.) y las rutas de los medios por las del proyecto.
  6. Registra el proyecto en js/proyectos-data.js (ver ejemplo abajo). Mientras no tenga entrada ahí, la página no aparece en el index ni en la galería.
  7. Al publicar: borra la meta robots (noindex) del <head>, borra esta tarjeta completa y los estilos .tpl-* del bloque <style>.

Convención de colores de los badges
  • bg-warning text-dark productor ONIRIS-ID.
  • bg-danger productor UAC y herramientas (SolidWorks, Klipper).
  • bg-primary cliente Armada, IoT.
  • bg-success áreas: Programación, Software, Automatización, Prototipado.
  • bg-info tecnologías: Sensores, 3D Printing, OrcaSlicer, Robótica, Raspberry Pi.
  • bg-secondary disciplina: Mecatrónica, Mecánica, Control.

Los badges del sidebar deben coincidir con el arreglo badges de la entrada del proyecto en js/proyectos-data.js (mismo texto y misma clase).

Registrar el proyecto en js/proyectos-data.js

Agrega un objeto como este dentro del arreglo proyectosData. Las rutas image, video y link son relativas a la raíz del sitio (sin ../). 

{
    id: 'mi-proyecto',                 // identificador único, en minúsculas y con guiones
                                       // (ya usados: simulador-bote, encoders-m250, granja-3d,
                                       //  scorbot, sensoracore, momo-boat)
    title: 'Nombre del Proyecto',      // título de la tarjeta en el index y la galería
    description: 'Descripción breve del proyecto en una o dos frases.', // texto corto de la tarjeta
    image: 'assets/img/MiProyecto/principal.jpg',  // imagen de la tarjeta (desde la raíz, sin ../)
    video: null,                       // null, o un mp4: 'assets/vid/MiProyecto/Video.mp4'
    link: 'proyectos/Mi_Proyecto.html',// ruta de esta página (desde la raíz)
    tags: ['uac', 'programación', 'iot', 'mecatrónica', 'mi-proyecto'],
                                       // minúsculas; los usa el buscador y los chips de filtro
    badges: [                          // los mismos badges que pongas en el sidebar
        { text: 'UAC', class: 'bg-danger' },
        { text: 'Programación', class: 'bg-success' },
        { text: 'IoT', class: 'bg-primary' },
        { text: 'Mecatrónica', class: 'bg-secondary' }
    ],
    featured: false,                   // true = aparece en "destacados" del index (si visible es true)
    visible: true                      // false = oculto en el index y en la galería
},

Tags y chips de filtro: los chips de galeria.html se definen en filterGroups, en el mismo archivo. Un chip solo encuentra proyectos si su tag coincide con un valor de tags (sin importar mayúsculas). Dentro de un grupo los chips se combinan con O; entre grupos, con Y. Si el proyecto introduce una tecnología nueva, agrega el tag al proyecto y, si quieres un chip para ella, agrégalo al grupo correspondiente: 

const filterGroups = [
    {
        title: 'Productores',
        chips: [
            { label: 'Armada', tag: 'armada' },
            { label: 'ONIRIS-ID', tag: 'oniris-id' },
            { label: 'UAC', tag: 'uac' }
        ]
    },
    {
        title: 'Tecnologías',
        chips: [
            { label: 'IoT', tag: 'iot' },
            { label: '3D Printing', tag: '3d printing' },
            { label: 'Nueva Tecnología', tag: 'nueva tecnología' }  // nuevo chip de ejemplo
        ]
    },
    {
        title: 'Area',
        chips: [
            { label: 'Programación', tag: 'programación' }
        ]
    }
];

Colecciones: las carpetas de galeria.html se definen en el arreglo colecciones, en el mismo archivo. Agrega el id del nuevo proyecto a la lista projects de cada colección a la que pertenezca (por ejemplo projects: ['simulador-bote', 'mi-proyecto']). Los ids que no existan se ignoran y las imágenes de la carpeta salen solas del campo image.

Errores que no se deben copiar
  • Cierra cada <div class="row g-3"> de la galería; al comentar un video no comentes también el </div> de la fila.
  • No dejes etiquetas sueltas (</style>, </script>, </main> duplicado) al final de <main>.
  • Llena siempre el alt de las imágenes de galería: es el texto que aparece debajo en el visor.
  • Usa bi-bullseye para "Objetivos": el ícono bi-target no existe en bootstrap-icons 1.11.3.
  • Cada carpeta animada necesita su propio id de collapse; los id nunca se repiten.
  • En el Reconocimiento usa <div class="blockquote-footer"> y no <footer>: la regla global footer le pone el fondo del pie de página.
  • No escribas dos guiones seguidos dentro de un comentario HTML (rompe el comentario en algunos validadores).
Clases útiles de css/proyectos.css
  • .project-hero, .project-sidebar: tarjetas con fondo y borde según el tema (claro/oscuro).
  • .project-title, .project-meta, .project-tech: título, fila de badges y lista de tecnologías.
  • .gallery-img: miniatura con cursor de zoom; además es la clase que js/proyectos.js usa para abrir el visor.
  • blockquote.blockquote y .blockquote-footer: tarjeta de cita con borde de color y comillas.
  • .ai-folder, .ai-folder-back, .ai-folder-sheet (.ai-sheet-1/2/3), .ai-folder-front, .ai-folder-content: carpeta animada.
  • .image-container, #modalImage, .zoom-controls: visor de imágenes.
  • Variables del tema: --text, --bg, --card-bg, --border, --bs-primary... Usa estas en lugar de colores fijos o de alert-* / bg-light para que el modo oscuro funcione.
  • .gallery-item y .video-container existen pero ninguna página las usa; usa .ratio de Bootstrap.
  • .sc-eol NO está en proyectos.css: va en el <style> de esta página.
