Resumen General del Sistema

Descripción del Proyecto

SensoraCore es un sistema completo de monitoreo de sensores basado en ESP32 con MicroPython, que proporciona una solución integrada para la adquisición, procesamiento y visualización de datos de múltiples tipos de sensores.

Firmware Embebido

  • MicroPython en ESP32
  • 11 módulos de sensores
  • Servidor TCP/IP integrado
  • Calibración en tiempo real
  • Pantalla OLED informativa

Aplicación Desktop

  • PySide6 (Qt for Python)
  • Interfaz gráfica intuitiva
  • Gráficos en tiempo real
  • Exportación Excel/CSV
  • Calibración asistida

Comunicación

  • Protocolo TCP/IP WiFi
  • Puerto 8080
  • Comandos ASCII simples
  • Stream de datos continuo
  • Baja latencia

Firmware Embebido (MicroPython)

Descripción General

Lenguaje y entorno: Implementado en MicroPython por su ligereza y compatibilidad con microcontroladores, permitiendo programación modular y rápida iteración.

Funciones Principales:

  • Lectura de sensores: Conversión analógica-digital (ADC) para sensores como LM35 y MQ2; manejo de protocolos digitales (OneWire para DS18B20, SPI para MAX6675, I²C para TCS3200).
  • Preprocesamiento: Filtrado básico de señales, compensación térmica (ej. HC-SR04) y normalización de datos.
  • Calibración embebida: Aplicación de algoritmos de regresión lineal, polinómica y logarítmica según el tipo de sensor.
  • Comunicación: Transmisión de datos mediante protocolo TCP/IP sobre Wi-Fi, asegurando estabilidad y baja latencia.

Estructura Modular:

Scripts dedicados por tipo de sensor (main_parte1_distancia_angulo.py, main_parte3_gases_temperatura.py, etc.), facilitando la escalabilidad y mantenimiento.

MicroPython Función: read_adc_filtered() - Lectura ADC con filtrado 
def read_adc_filtered(adc_obj, samples=5):
    """Lee el ADC con promedio de múltiples muestras para reducir ruido
    
    Parámetros:
        adc_obj: Objeto ADC configurado
        samples: Número de muestras a promediar (default: 5)
    
    Retorna:
        int: Valor promediado del ADC (0-4095 para 12 bits)
    """
    total = 0
    for _ in range(samples):
        total += adc_obj.read()
        time.sleep_ms(1)  # Pequeña pausa entre lecturas
    
    return total // samples  # División entera para promedio

# Ejemplo de uso con mapeo a rango físico
def map_value(value, in_min, in_max, out_min, out_max):
    """Mapea un valor de un rango a otro"""
    return int((value - in_min) * (out_max - out_min) / (in_max - in_min) + out_min)

# Uso: Convertir ADC (0-4095) a ángulo (-135° a +135°)

3 Sensor de Temperatura LM35

MicroPython Función: read_lm35() - Lectura de temperatura analógica 
def read_lm35():
    """Lee LM35 con compensación de no-linealidad del ADC ESP32
    NOTA: LM35 alimentado a 5V, pero ADC ESP32 lee máximo 3.3V
    """
    if lm35_adc is None:
        return -999
    try:
        # Promediar múltiples lecturas para estabilidad
        raw = read_adc_filtered(lm35_adc, samples=20)
        
        # Compensación de no-linealidad del ADC ESP32
        # El ADC ESP32 es no-lineal en los extremos (0-150mV y 3150-3300mV)
        # Rango útil: 150mV - 3150mV (aprox 150-4000 ADC)
        
        # IMPORTANTE: ADC ESP32 lee máximo 3.3V aunque LM35 esté a 5V
        # LM35 con Vcc=5V puede dar hasta 1.5V (150°C)
        voltage = (raw / 4095.0) * 3.3
        
        # LM35: 10mV/°C (0.01V/°C) sin importar Vcc
        # La salida es proporcional a temperatura, no a Vcc
        # Fórmula: Temp(°C) = Voltage(V) × 100
        temp_c = voltage * 100.0
        
        # Validar rango físico del LM35
        # Rango medible: 0°C a 150°C (0V a 1.5V)
        if temp_c < -10 or temp_c > 150:
            return -999
        
        return round(temp_c, 2)
    except Exception as e:
        print(f"[LM35] Error lectura: {e}")
        return -999

def read_ds18b20():
    """Lee DS18B20 digital con protocolo OneWire"""
    if ds_sensor is None or ds_rom is None:
        return -999
    try:
        # Iniciar conversión de temperatura
        ds_sensor.convert_temp()
        
        # Esperar tiempo de conversión según resolución:
        # 9-bit: 93.75ms, 10-bit: 187.5ms, 11-bit: 375ms, 12-bit: 750ms
        # Por defecto usa 12-bit (máxima precisión: 0.0625°C)
        time.sleep_ms(750)
        
        # Leer temperatura
        temp_c = ds_sensor.read_temp(ds_rom)
        
        # Validar rango DS18B20 (-55°C a +125°C)
        if temp_c < -55 or temp_c > 125:
            print(f"[DS18B20] Temp fuera de rango: {temp_c}°C")
            return -999
        
        # Verificar lectura válida (DS18B20 devuelve 85°C si hay error)
        if temp_c == 85.0:
            print("[DS18B20] Lectura de error (85°C) - sensor no listo")
            return -999
        
        return round(temp_c, 2)
    except OSError as e:
        print(f"[DS18B20] Error OneWire: {e}")
        return -999
    except Exception as e:
        print(f"[DS18B20] Error lectura: {e}")
        return -999

5 Sensor SPI MAX6675 (Termopar)

MicroPython Función: read_max6675() - Lectura termopar tipo K via SPI 
def read_max6675():
    """Lee MAX6675 (termopar Type-K) vía SPI"""
    if spi is None or cs is None:
        return -999
    
    try:
        # Activar chip (CS LOW)
        cs.value(0)
        time.sleep_us(1)  # Tiempo de setup
        
        # Leer 2 bytes (16 bits) del MAX6675
        data = spi.read(2)
        
        # Desactivar chip (CS HIGH)
        cs.value(1)
        
        if len(data) != 2:
            print("[MAX6675] Error: datos incompletos")
            return -999
        
        # Combinar bytes (MSB primero)
        raw = (data[0] << 8) | data[1]
        
        # Verificar bit D2 (termopar desconectado)
        if raw & 0x0004:
            print("[MAX6675] ERROR: Termopar desconectado")
            return -999
        
        # Verificar bit 0 (debe ser 0 para MAX6675 válido)
        if raw & 0x0001:
            print("[MAX6675] ERROR: Bit de ID inválido")
            return -999
        
        # Extraer temperatura: bits [14:3] = 12 bits
        temp_bits = (raw >> 3) & 0x0FFF
        
        # Conversión: cada bit = 0.25°C (resolución 12-bit)
        temp_c = temp_bits * 0.25
        
        # Validar rango MAX6675 (0°C a +1024°C)
        if temp_c < 0 or temp_c > 1024:
            print(f"[MAX6675] Temp fuera de rango: {temp_c}°C")
            return -999
        
        return round(temp_c, 2)
        
    except Exception as e:
        print(f"[MAX6675] Error lectura SPI: {e}")
        return -999

6 Sensor de Gases MQ (MQ2/MQ3)

MicroPython Función: read_mq_sensor() - Cálculo PPM con curva logarítmica 
def read_mq_sensor(adc, sensor_name, samples=20, R0=None, RL=10000.0):
    """
    Lectura filtrada de sensor MQ con algoritmo PPM real basado en Rs/R0
    
    Parámetros:
    - adc: ADC configurado
    - sensor_name: 'MQ2' o 'MQ3'
    - samples: muestras para promedio (default 20)
    - R0: Resistencia del sensor en aire limpio (calibración)
    - RL: Resistencia de carga en el módulo (típicamente 10kΩ)
    
    Retorna: (raw, voltage, Rs, ppm) o None si hay error
    """
    if not adc:
        return None
    
    try:
        raw = read_adc_filtered(adc, samples=samples)
        
        # Voltaje de salida del sensor (0-3.3V)
        voltage = (raw / 4095.0) * 3.3
        
        # Protección contra división por cero
        if voltage < 0.01:
            voltage = 0.01
        
        # Calcular Rs (resistencia del sensor)
        # Vcc = 5V (alimentación del sensor)
        # Formula: Rs = RL * (Vcc - Vout) / Vout
        Vcc = 5.0
        Rs = RL * (Vcc - voltage) / voltage
        
        # Valores R0 por defecto si no hay calibración
        if R0 is None:
            if sensor_name == 'MQ2':
                R0 = 10000.0  # Valor típico del datasheet
            elif sensor_name == 'MQ3':
                R0 = 60000.0  # Valor típico del datasheet
            else:
                R0 = 10000.0
        
        # Calcular ratio Rs/R0
        ratio = Rs / R0
        
        # Curvas características logarítmicas del datasheet
        # Ecuación: log10(PPM) = m * log10(Rs/R0) + b
        
        if sensor_name == 'MQ2':
            # MQ2 - Curva H2: m = -0.45, b = 2.3 (200-10000 PPM)
            m = -0.45
            b = 2.3
            ppm_min, ppm_max = 200.0, 10000.0
        elif sensor_name == 'MQ3':
            # MQ3 - Curva alcohol: m = -0.36, b = 2.0 (25-500 PPM)
            m = -0.36
            b = 2.0
            ppm_min, ppm_max = 25.0, 500.0
        else:
            ppm = 0.0
        
        if ratio <= 0:
            ppm = ppm_min
        else:
            import math
            log_ratio = math.log10(ratio)
            log_ppm = m * log_ratio + b
            ppm = 10 ** log_ppm
            if ppm < ppm_min:
                ppm = ppm_min
            elif ppm > ppm_max:
                ppm = ppm_max
        
        return (raw, voltage, Rs, ppm)
    
    except Exception as e:
        print(f"[{sensor_name}] Error: {e}")
        return None

MicroPython Función: distancia_ultrasonico_loop() - Medición por pulsos 
def distancia_ultrasonico_loop(client):
    """Loop del módulo HC-SR04 con cálculo de distancia"""
    while current_mode == 'DISTANCIA_ULTRA':
        # Generar pulso trigger (10μs)
        trigger_pin.off()
        time.sleep_us(2)
        trigger_pin.on()
        time.sleep_us(10)
        trigger_pin.off()
        
        # Medir tiempo de echo con timeout (30ms)
        timeout_us = 30000
        
        # Esperar inicio de echo
        start_time = time.ticks_us()
        timeout_start = start_time
        while echo_pin.value() == 0:
            start_time = time.ticks_us()
            if time.ticks_diff(start_time, timeout_start) > timeout_us:
                break
        
        # Medir duración del echo
        end_time = start_time
        while echo_pin.value() == 1:
            end_time = time.ticks_us()
            if time.ticks_diff(end_time, start_time) > timeout_us:
                break
        
        # Calcular distancia
        duration = time.ticks_diff(end_time, start_time)
        
        if 0 < duration < timeout_us:
            # Velocidad del sonido: 343 m/s = 0.0343 cm/μs
            # Distancia = (tiempo × velocidad) / 2
            distancia_cm = (duration * 0.0343) / 2
        else:
            distancia_cm = -1  # Error o fuera de rango
        
        # Actualizar OLED
        if distancia_cm >= 0:
            oled_write("Ultrasonic", "-" * 16, f"Dist: {distancia_cm:.1f}cm", "", "")
        else:
            oled_write("Ultrasonic", "-" * 16, "Fuera rango", "", "")
        
        # Enviar datos
        msg = f"ULTRA_CM:{distancia_cm:.1f}\n"
        client.sendall(msg.encode())
        
        time.sleep(0.06)  # ~16 Hz

def select_filter(color):
    """Selecciona filtro de color: RED, GREEN, BLUE, CLEAR"""
    if color == 'RED':
        s2.value(0)
        s3.value(0)
    elif color == 'GREEN':
        s2.value(1)
        s3.value(1)
    elif color == 'BLUE':
        s2.value(0)
        s3.value(1)
    else:  # CLEAR
        s2.value(1)
        s3.value(0)

def time_pulse_us(pin, level, timeout_us):
    """Mide duración de pulso (similar a pulseIn de Arduino)"""
    start = time.ticks_us()
    # Esperar nivel opuesto
    while pin.value() == level:
        if time.ticks_diff(time.ticks_us(), start) > timeout_us:
            return 0
    # Esperar nivel deseado
    while pin.value() != level:
        if time.ticks_diff(time.ticks_us(), start) > timeout_us:
            return 0
    # Medir duración
    pulse_start = time.ticks_us()
    while pin.value() == level:
        if time.ticks_diff(time.ticks_us(), pulse_start) > timeout_us:
            return 0
    return time.ticks_diff(time.ticks_us(), pulse_start)

def measure_pulse_width(color):
    """Mide ancho de pulso para un color específico"""
    select_filter(color)
    time.sleep_ms(20)  # Estabilización
    
    pulse_width = time_pulse_us(out_pin, 0, 50000)
    return pulse_width if pulse_width > 0 else 0

1 Cliente TCP para Comunicación

Python Clase: AngleArmThread - Hilo de comunicación TCP 
from PySide6.QtCore import QThread, Signal
import socket

class AngleArmThread(QThread):
    """Thread para comunicación TCP y procesamiento de datos en tiempo real"""
    data_received = Signal(str)
    connection_status = Signal(str)
    
    def __init__(self, ip, port, parent=None):
        super().__init__(parent)
        self.ip = ip
        self.port = port
        self.socket = None
        self.running = False
        self.buffer = ""
    
    def run(self):
        """Bucle principal del thread"""
        try:
            self.socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            self.socket.settimeout(5)
            self.socket.connect((self.ip, self.port))
            self.connection_status.emit("Conectado")
            self.running = True
            
            # Enviar comando de cambio de modo
            command = "MODO:ANGULO_BRAZO\n"
            self.socket.sendall(command.encode('utf-8'))
            
            while self.running:
                try:
                    data = self.socket.recv(256).decode('utf-8')
                    if not data:
                        break
                    
                    self.buffer += data
                    # Procesar líneas completas
                    while '\n' in self.buffer:
                        line, self.buffer = self.buffer.split('\n', 1)
                        self.data_received.emit(line.strip())
                
                except socket.timeout:
                    continue
                except Exception as e:
                    self.connection_status.emit(f"Error: {e}")
                    break
        
        finally:
            self.stop()
    
    def stop(self):
        """Detiene el thread y cierra socket"""
        self.running = False
        if self.socket:
            self.socket.close()
        self.connection_status.emit("Desconectado")

2 Calibración Lineal (Regresión)

Python Función: calibrar() - Calibración por regresión lineal 
import numpy as np
import scipy.stats
from PySide6.QtWidgets import QMessageBox

def calibrar(self):
    """Ejecuta calibración lineal con los datos actuales (y = mx + b)"""
    if len(self.raw_values) < 2:
        QMessageBox.warning(self, "Error", "Mínimo 2 puntos requeridos")
        return
    
    try:
        x_data = np.array(self.raw_values)        # Valores ADC crudos
        y_data = np.array(self.actual_values)     # Valores reales (calibrados)
        
        # Regresión lineal: y = slope*x + intercept
        self.slope, self.intercept, r_value, _, _ = scipy.stats.linregress(x_data, y_data)
        r_squared = r_value ** 2
        
        # Actualizar UI con ecuación
        equation = f"y = {self.slope:.4f}x + {self.intercept:.4f}"
        self.ui.label_ecuacion.setText(equation)
        self.ui.label_r2.setText(f"R² = {r_squared:.6f}")
        
        # Graficar regresión
        self.ax2.clear()
        self.ax2.scatter(x_data, y_data, color='blue', label='Datos', s=60, zorder=3)
        
        x_line = np.linspace(x_data.min(), x_data.max(), 100)
        y_line = self.slope * x_line + self.intercept
        self.ax2.plot(x_line, y_line, 'r-', label='Ajuste', linewidth=2, zorder=2)
        
        self.ax2.set_xlabel('Valor Crudo (ADC)', fontsize=10)
        self.ax2.set_ylabel('Valor Real (unidades físicas)', fontsize=10)
        self.ax2.set_title(f'Calibración: {equation}', fontsize=11, weight='bold')
        self.ax2.legend(loc='best')
        self.ax2.grid(True, alpha=0.3, linestyle='--')
        self.canvas2.draw()
        
        self.calibrated = True
        QMessageBox.information(self, "Éxito", f"{equation}\nR² = {r_squared:.6f}")
        
    except Exception as e:
        QMessageBox.critical(self, "Error", f"Fallo: {e}")

        self, "Guardar datos",
        f"sensora_{datetime.now().strftime('%Y%m%d_%H%M%S')}.xlsx",
        "Excel (*.xlsx)"
    )
    
    if not filename:
        return
    
    try:
        # Crear DataFrame con datos alineados
        max_len = max(len(self.data_hombro), len(self.data_codo))
        
        df = pd.DataFrame({
            'Tiempo_Hombro (s)': pd.Series(self.timestamps_hombro),
            'Hombro (°)': pd.Series(self.data_hombro),
            'Tiempo_Codo (s)': pd.Series(self.timestamps_codo),
            'Codo (°)': pd.Series(self.data_codo)
        })
        
        # Crear Excel con XlsxWriter engine
        with pd.ExcelWriter(filename, engine='xlsxwriter') as writer:
            df.to_excel(writer, sheet_name='Datos', index=False)
            
            workbook = writer.book
            worksheet = writer.sheets['Datos']
            
            # Formato de columnas
            num_fmt = workbook.add_format({'num_format': '0.00'})
            worksheet.set_column('A:D', 18, num_fmt)
            
            # Crear gráfica embebida
            chart = workbook.add_chart({'type': 'line'})

            chart.add_series({
                'name': 'Hombro',
                'categories': ['Datos', 1, 0, max_len, 0],
                'values': ['Datos', 1, 1, max_len, 1],
                'line': {'color': 'blue', 'width': 2}
            })
            
            # Serie Codo
            chart.add_series({
                'name': 'Codo',
                'categories': ['Datos', 1, 2, max_len, 2],
                'values': ['Datos', 1, 3, max_len, 3],
                'line': {'color': 'red', 'width': 2}
            })
            
            chart.set_title({'name': 'Monitoreo de Ángulos'})
            chart.set_x_axis({'name': 'Tiempo (s)'})

            chart.set_style(10)

4 Visualización en Tiempo Real

Python Función: _on_data() - Actualización de gráficos matplotlib 
import time

def _on_data(self, data_line):
    """Procesa datos recibidos del ESP32 y actualiza visualización en tiempo real
    
    Args:
        data_line (str): Línea de datos formato "SENSOR1:valor1,SENSOR2:valor2"
    """
    try:
        if ':' not in data_line:
            return  # Línea inválida
        
        # Parsear datos (ejemplo para módulo de ángulos)
        parts = data_line.split(',')
        hombro_val = None
        codo_val = None
        
        for part in parts:
            if 'HOMBRO' in part:
                hombro_val = float(part.split(':')[1])
            elif 'CODO' in part:
                codo_val = float(part.split(':')[1])
        
        # Aplicar calibración si está activa
        if self.calibrated and self.slope is not None:
            if hombro_val is not None:
                hombro_val = self.slope * hombro_val + self.intercept
            if codo_val is not None:
                codo_val = self.slope * codo_val + self.intercept
        
        # Timestamp relativo
        current_time = time.time() - self.start_time
        
        # Actualizar datos y LCDs
        if hombro_val is not None:
            self.timestamps_hombro.append(current_time)
            self.data_hombro.append(hombro_val)
            self.ui.lcd_hombro.display(f"{hombro_val:.2f}")
        
        if codo_val is not None:
            self.timestamps_codo.append(current_time)
            self.data_codo.append(codo_val)
            self.ui.lcd_codo.display(f"{codo_val:.2f}")
        
        # Limitar ventana de datos (últimos 100 puntos)
        MAX_POINTS = 100
        if len(self.data_hombro) > MAX_POINTS:
            self.timestamps_hombro = self.timestamps_hombro[-MAX_POINTS:]
            self.data_hombro = self.data_hombro[-MAX_POINTS:]
        if len(self.data_codo) > MAX_POINTS:
            self.timestamps_codo = self.timestamps_codo[-MAX_POINTS:]
            self.data_codo = self.data_codo[-MAX_POINTS:]
        
        # Actualizar gráfica en tiempo real
        self.ax.clear()
        self.ax.plot(self.timestamps_hombro, self.data_hombro, 
                     'b-', linewidth=2, marker='o', markersize=3, label='Hombro')
        self.ax.plot(self.timestamps_codo, self.data_codo, 
                     'r-', linewidth=2, marker='s', markersize=3, label='Codo')
        
        self.ax.set_xlabel('Tiempo (s)', fontsize=10)
        self.ax.set_ylabel('Ángulo (°)', fontsize=10)
        self.ax.set_title('Monitoreo en Tiempo Real', fontsize=12, weight='bold')
        self.ax.legend(loc='upper right')
        self.ax.grid(True, alpha=0.3, linestyle='--')
        self.canvas.draw()
        
    except Exception as e:
        print(f"[Error] _on_data: {e}")

def load_calibration(self):
    """Carga parámetros de calibración desde archivo JSON"""
    try:
        if not os.path.exists("calibration.json"):
            raise FileNotFoundError("Archivo de calibración no encontrado")

    except Exception as e:
        QMessageBox.warning(self, "Advertencia", f"No se pudo cargar: {e}")

Protocolo de Comunicación TCP/IP

Formato de Comunicación

La comunicación entre el ESP32 y la aplicación de escritorio se realiza mediante sockets TCP/IP. El ESP32 actúa como servidor TCP, escuchando conexiones entrantes en el puerto 8888.

  • Cada trama termina con salto de línea (\n)

  • La reconexión automática se activa tras 3 intentos fallidos
Python Ejemplo: Parseo de datos en aplicación Desktop 
def parse_data(data_line):
    """Parsea línea de datos del ESP32
    
    Args:
        data_line (str): Línea con formato "KEY1:val1,KEY2:val2,..."
    
    Returns:
        dict: Diccionario con pares clave-valor
    """
    data_dict = {}
    
    try:
        # Separar por comas
        parts = data_line.strip().split(',')
        
        for part in parts:
            if ':' in part:
                key, value = part.split(':', 1)
                
                # Intentar conversión a float
                try:
                    data_dict[key.strip()] = float(value.strip())
                except ValueError:
                    data_dict[key.strip()] = value.strip()
        
        return data_dict
        
    except Exception as e:
        print(f"Error parsing data: {e}")
        return {}

# Ejemplo de uso
data = parse_data("HOMBRO:1234,CODO:2345,MUNECA:3456")
print(data)  # {'HOMBRO': 1234.0, 'CODO': 2345.0, 'MUNECA': 3456.0}

Algoritmos de Calibración

Los sensores requieren calibración para convertir valores brutos (ADC, voltaje, frecuencia) en unidades físicas (°C, °, cm, ppm). SensoraCore implementa múltiples algoritmos matemáticos adaptados a cada tipo de sensor.

1 Calibración Lineal (Sensores Analógicos)

Ecuación: y = m·x + b

Aplicable a: Potenciómetros, LDR, CNY70, LM35, Ultrasónico

Método: Regresión lineal por mínimos cuadrados

Python Implementación de calibración lineal con scipy 
from scipy.stats import linregress
import numpy as np

def calibrate_linear(adc_values, physical_values):
    """Realiza calibración lineal por regresión de mínimos cuadrados
    
    Args:
        adc_values (list): Valores ADC medidos (0-4095)
        physical_values (list): Valores físicos correspondientes (°, cm, lux, etc.)
    
    Returns:
        tuple: (slope, intercept, r_squared)
    """
    # Convertir a arrays numpy
    x = np.array(adc_values, dtype=float)
    y = np.array(physical_values, dtype=float)
    
    # Regresión lineal
    slope, intercept, r_value, p_value, std_err = linregress(x, y)
    r_squared = r_value ** 2
    
    return slope, intercept, r_squared

# Ejemplo: Calibración de sensor de ángulo
adc_calibration = [0, 512, 1024, 2048, 3072, 4095]
angle_calibration = [0, 30, 60, 120, 180, 240]

m, b, r2 = calibrate_linear(adc_calibration, angle_calibration)
print(f"Ecuación: y = {m:.4f}x + {b:.4f}")
print(f"R² = {r2:.4f}")  # R² cercano a 1 indica buen ajuste

2 Calibración Logarítmica (Sensores de Gas MQ)

Ecuación: log(PPM) = m·log(Rs/R0) + b

Aplicable a: MQ2 (humo, gas combustible), MQ3 (alcohol)

Método: Regresión logarítmica en escala log-log

Python Calibración logarítmica para sensores MQ 
import numpy as np
from scipy.stats import linregress

def calibrate_mq_sensor(rs_r0_values, ppm_values):
    """Calibra sensor MQ con curva logarítmica
    
    Args:
        rs_r0_values (list): Ratios Rs/R0 medidos
        ppm_values (list): Concentraciones PPM conocidas
    
    Returns:
        tuple: (slope_log, intercept_log, r_squared)
    """
    # Transformación logarítmica
    log_rs_r0 = np.log10(rs_r0_values)
    log_ppm = np.log10(ppm_values)
    
    # Regresión en espacio log-log
    slope, intercept, r_value, _, _ = linregress(log_rs_r0, log_ppm)
    r_squared = r_value ** 2
    
    return slope, intercept, r_squared

# Datos de calibración MQ2 (ejemplo con gas propano)
rs_r0 = [9.8, 3.0, 1.5, 0.8, 0.4]
ppm = [200, 500, 1000, 2000, 5000]

m_log, b_log, r2 = calibrate_mq_sensor(rs_r0, ppm)

# Función de conversión calibrada
def rs_r0_to_ppm(rs_r0_ratio):
    log_ppm = m_log * np.log10(rs_r0_ratio) + b_log
    return 10 ** log_ppm

3 Calibración Polinómica (Termorregulación Avanzada)

Ecuación: y = a₀ + a₁x + a₂x² + ... + aₙxⁿ

Aplicable a: Termopares (MAX6675), sensores no lineales

Método: Ajuste polinómico de grado n

Python Calibración polinómica con numpy 
import numpy as np

def calibrate_polynomial(x_values, y_values, degree=2):
    """Calibración polinómica de grado n
    
    Args:
        x_values (list): Valores de entrada (voltaje, ADC, etc.)
        y_values (list): Valores de salida (temperatura, etc.)
        degree (int): Grado del polinomio (2 = cuadrático, 3 = cúbico)
    
    Returns:
        numpy.poly1d: Objeto polinomio para evaluación
    """
    coefficients = np.polyfit(x_values, y_values, degree)
    polynomial = np.poly1d(coefficients)
    return polynomial

# Ejemplo: Termopar tipo K (MAX6675)
voltage_mv = [0, 4.1, 8.1, 12.2, 16.4]
temp_c = [0, 100, 200, 300, 400]

poly = calibrate_polynomial(voltage_mv, temp_c, degree=2)

# Uso del polinomio
measured_voltage = 10.5
temperature = poly(measured_voltage)
print(f"Temperatura: {temperature:.2f}°C")

4 Compensación Térmica (Sensores de Distancia)

Problema: La velocidad del sonido varía con la temperatura: v = 331.3 + 0.606·T

Solución: Ajustar mediciones de distancia ultrasónica según temperatura ambiente

Python Compensación térmica para HC-SR04 
def compensate_temperature(distance_cm, temp_celsius):
    """Compensa distancia ultrasónica según temperatura
    
    Args:
        distance_cm (float): Distancia medida en cm
        temp_celsius (float): Temperatura ambiente en °C
    
    Returns:
        float: Distancia compensada
    """
    # Velocidad del sonido a 20°C (referencia)
    v_ref = 343.0  # m/s
    
    # Velocidad corregida por temperatura
    v_actual = 331.3 + 0.606 * temp_celsius
    
    # Factor de corrección
    correction_factor = v_actual / v_ref
    
    return distance_cm * correction_factor

5 Normalización RGB (Sensor TCS3200)

Objetivo: Independizar lecturas de color de la intensidad lumínica ambiente

Método: Normalización por canal CLEAR

Python Normalización RGB con TCS3200 
def normalize_rgb(r, g, b, clear):
    """Normaliza valores RGB por intensidad total
    
    Args:
        r, g, b (int): Valores RGB brutos
        clear (int): Valor de canal CLEAR (intensidad total)
    
    Returns:
        tuple: (r_norm, g_norm, b_norm) en rango [0, 255]
    """
    if clear == 0:
        return 0, 0, 0
    
    # Normalización por intensidad
    r_norm = (int)((float(r) / clear) * 255)
    g_norm = (int)((float(g) / clear) * 255)
    b_norm = (int)((float(b) / clear) * 255)
    
    return r_norm, g_norm, b_norm
