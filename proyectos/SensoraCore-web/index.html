📋 Sobre el Proyecto

SensoraCore es un sistema completo de monitoreo de sensores que combina hardware ESP32 y software de escritorio desarrollado en Python con PySide6. Proyecto creado el 25 de Mayo de 2024 y diseñado para aplicaciones educativas y de prototipado, permite la lectura, visualización y análisis de múltiples tipos de sensores a través de conexión WiFi.

🎯 Objetivo

Desarrollar módulos didácticos para la caracterización y calibración de sensores industriales, proporcionando una plataforma accesible y robusta para el aprendizaje y desarrollo de proyectos IoT. El sistema facilita la integración de sensores digitales y analógicos con capacidad de análisis en tiempo real, calibración persistente y exportación de datos para análisis científico.

💡 Ideal para: Estudiantes, educadores, makers, ingenieros y desarrolladores interesados en IoT, robótica y sistemas embebidos.

✨ Características Principales

📡 Conectividad WiFi

Comunicación inalámbrica TCP/IP entre ESP32 y aplicación de escritorio con reconexión automática.

🔌 12+ Sensores Soportados

Potenciómetros, infrarojos, capacitivos, ultrasónicos, temperatura, gases, color y más.

📊 Visualización en Tiempo Real

Gráficas dinámicas con matplotlib y actualización instantánea de datos.

📁 Exportación Excel

Guarda tus mediciones con gráficos embebidos y estadísticas automáticas.

🎨 Interfaz Intuitiva

UI moderna desarrollada con PySide6, fácil de usar y visualmente atractiva.

🔧 Calibración Integrada

Sistema de calibración lineal y guardado de parámetros por sensor.

🚀 Inicio Rápido

1️⃣ Configurar ESP32

Paso 1: Edita SensoraCoreESP32/wifi_config.py con tus credenciales WiFi:

SSID = 'TuRedWiFi'
PASSWORD = 'TuContraseña'

Paso 2: Sube el código al ESP32 usando Thonny, uPyCraft o ampy

Paso 3: Anota la IP que aparece en el monitor serial (ej: 192.168.1.100)

2️⃣ Ejecutar Aplicación

cd SensoraCoreApp
pip install -r requirements.txt
python main.py

3️⃣ Conectar y Monitorear

  • Ingresa la IP del ESP32 en la aplicación
  • Presiona "Conectar y encender LED integrado"
  • Selecciona un sensor de la lista
  • Observa los datos en tiempo real
  • Exporta a Excel cuando lo necesites
📖 Más detalles: Consulta el QUICKSTART.md completo para instrucciones detalladas de cada sensor.

🏗️ Arquitectura del Sistema

Hardware

  • Microcontrolador: ESP32 con WiFi integrado
  • Sensores: Digitales y analógicos de diversos tipos
  • Comunicación: TCP/IP sobre WiFi
  • Display opcional: OLED I2C para estado local

Software - Firmware ESP32

  • Lenguaje: MicroPython
  • Protocolo: Servidor TCP en puerto 8080
  • Formato de datos: Texto plano "SENSOR:valor"
  • Módulos principales: red.py, main.py

Software - Aplicación Desktop

  • Framework: PySide6 (Qt for Python)
  • Visualización: matplotlib para gráficos
  • Exportación: openpyxl para Excel
  • Arquitectura: Módulos por sensor con threading

🔧 Solución de Problemas

ESP32 no se conecta al WiFi

  • Verifica SSID y contraseña en wifi_config.py
  • Asegúrate que la red WiFi esté disponible y sea 2.4GHz
  • Reinicia el ESP32 y verifica el monitor serial

App no puede conectar al ESP32

  • Verifica que ESP32 esté encendido y conectado al WiFi
  • Usa la IP correcta mostrada en el monitor serial
  • Verifica que ambos estén en la misma red WiFi
  • Desactiva temporalmente el firewall para probar

Error al instalar dependencias

pip install --upgrade pip
pip install PySide6 matplotlib openpyxl scipy

Las gráficas no se muestran

✅ Solucionado en Beta 1.0: Las gráficas ahora se muestran correctamente desde el primer uso con renderizado mejorado.
